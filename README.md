# 🚀 AutoDS - Automated Data Science Platform

AutoDS is an end-to-end Data Science web application built with Streamlit that automates the complete machine learning workflow.

Users can upload a dataset and perform Data Cleaning, Exploratory Data Analysis (EDA), Data Visualization, Feature Engineering, and Machine Learning Model Training without writing code.

## ✨ Features

### 📂 Dataset Upload
- Upload CSV files
- Instant dataset preview
- Shape and data type information

### 🧹 Data Cleaning
- Missing value detection
- Missing value handling
- Duplicate row detection and removal
- Data type inspection

### 📊 Exploratory Data Analysis (EDA)
- Statistical summary
- Correlation analysis
- Distribution plots
- Feature exploration

### 📈 Data Visualization
- Histograms
- Boxplots
- Scatter plots
- Correlation heatmaps
- Interactive visual analysis

### 🚨 Outlier Detection
- IQR-based outlier detection
- Outlier visualization
- Column-wise analysis

### 🤖 Machine Learning
- Automatic target selection
- Classification support
- Regression support
- Train-Test Split
- Model Training
- Performance Evaluation

### 📉 Model Evaluation
- Accuracy Score
- R² Score
- Prediction Results
- Model Comparison
